# 02 — CI on Ubuntu and macOS

Stack 2/6. Every push and PR runs typecheck, unit, integration and pack smoke
tests on Linux and macOS, so later tickets are verified on both platforms.

## Scope

- `.github/workflows/ci.yml`, on `push` to `main` and `pull_request`.
- Matrix `os: [ubuntu-latest, macos-latest]` (macos-latest is arm64), Node 22.
- Steps: checkout → `pnpm/action-setup` (version from `packageManager`;
  add a `packageManager` field to `package.json` if missing) →
  `actions/setup-node` with pnpm cache → `pnpm install --frozen-lockfile` →
  install ffmpeg (`sudo apt-get install -y ffmpeg` / `brew install ffmpeg`;
  integration tests call `ffprobe`, see `src/cli/cli.int.spec.ts:31`) →
  `node node_modules/playwright-core/cli.js install --with-deps chromium`
  (Linux) / `install chromium` (macOS) → `pnpm typecheck` → `pnpm test` →
  `pnpm build` → `pnpm test:integration` → `pnpm test:pack`.
- Upload `test-output/` as an artifact on failure.

## Out of scope

- Publishing: 06. Tests for the ffmpeg fallback / first-run Chromium install
  belong to 03 / 04 and run here once merged.

## Done when

- Tests: the workflow is green on both OSes on a PR.
- GitHub: a deliberately failing unit test on a throwaway branch turns the run
  red (then drop the branch).
